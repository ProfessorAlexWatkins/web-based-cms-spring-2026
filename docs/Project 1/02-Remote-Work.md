<h1>Remote work policy</h1>
<p>Employees are allowed to work from home on Fridays.Please use the VPN when you are working from home.</p>

<h2>VPN access</h2>
<p>To access the file server from home,you need to set up Cisco and then log in via the VPN Network:
  <ol>
  <li>From file explorer, select the blue Cisco icon on your laptop.</li>
  <li> Follow the promts to set up Cisco, this will allow you to log in to the VPN. </li>
  <li> When you work from home, log in via Cisco to access the VPN Network.</li> 
  <li> Once logged in, you can acceess the online portal with your work.</li>
  </ol>
</p>
<p>For help getting set up, email sysadmin@acme.com.</p>
